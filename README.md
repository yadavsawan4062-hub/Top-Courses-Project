## 📌 About the Project

**Top Courses Project** is a React-based web application designed to make browsing different courses simple and interactive.

The application displays course information using reusable React components and dynamically renders course data fetched from an API.

The project helped me understand how different React components work together to build a functional and interactive user interface.

## ⚛️ React Concepts Practiced

While building this project, I practiced the following React concepts:

### 🔹 1. Components
Created reusable components to organize the application into smaller, manageable parts.

Examples:
- `App`
- `Card`
- `Cards`
- `Filter`
- `Navbar`
- `EnrollForm`
- `Spinner`

### 🔹 2. Props
Passed data between components to display course information dynamically.

### 🔹 3. State Management
Used React state to manage interactive UI behavior.

### 🔹 4. Event Handling
Implemented user interactions such as clicking buttons and selecting course categories.

### 🔹 5. Conditional Rendering
Displayed different UI elements depending on the application's state.

### 🔹 6. Lists and Dynamic Rendering
Used JavaScript's `map()` method to render course cards dynamically.

### 🔹 7. Filtering Data
Implemented category-based filtering to help users explore courses.

### 🔹 8. API Integration
Practiced fetching course data from an API and displaying it in the application.

### 🔹 9. Form Handling
Created an enrollment form to practice collecting user input.

### 🔹 10. Component-Based Architecture
Organized the project into reusable components for better maintainability.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/yadavsawan4062-hub/Top-Courses-Project.git
```

### 2. Navigate to the Project Directory

```bash
cd Top-Courses-Project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm start
```

Open the local URL displayed in your terminal to explore the application.
